# data_project_sharypova

**Проект для курса "Инжиниринг данных", базовый курс**

## Датасет

Термогравиметрический анализ (ТГА) гидрогелей на основе карбоксиметил-агара и желатина при разных значениях pH. Собран самостоятельно в процессе сбора данных для статьи.

**Структура данных:**
- Формат: CSV
- Строк: ~9 800
- Столбцов: 18 (температура, время, % массы, ДТГ, pH, состав образца и другие метаданные)
