# Инжиниринг данных термогравиметрического анализа

Проект выполнен в рамках дисциплины «Инжиниринг управления данными».

Цель проекта — разработка ETL-пайплайна для загрузки, преобразования, проверки качества и сохранения экспериментальных данных термогравиметрического анализа (ТГА) гидрогелей на основе карбоксиметилагара и желатина.

## 1. Описание данных

Используется собственный экспериментальный датасет, полученный при исследовании гидрогелей на основе карбоксиметилагара и желатина при разных значениях pH.

- Источник: [Google Drive](https://drive.google.com/file/d/1AzuOQPWF5PUckfjcGoHsmzs5hGJxtO7j/view?usp=sharing)
- Формат исходных данных: CSV
- Объём: 9 768 строк и 18 столбцов
- Размер исходного файла: около 2,2 МБ

Датасет включает температуру, время измерения, относительную массу образца, скорость изменения массы (ДТГ), pH, состав образца, номер измерения и дополнительные экспериментальные параметры.

Основной ETL-пайплайн находится в пакете `src/etl`. Остальные скрипты сохранены как результаты предыдущих домашних заданий.

Назначение файлов пакета:

- `extract.py` — загрузка исходных данных из Google Drive.
- `transform.py` — преобразование типов данных.
- `validate.py` — проверка структуры, полноты и основных экспериментальных величин.
- `load.py` — запись данных в PostgreSQL и проверка количества строк.
- `main.py` — последовательный запуск этапов ETL через командную строку.
- `__init__.py` — файл инициализации пакета Python.

Файл `notebooks/EDA.ipynb` содержит разведочный анализ экспериментальных данных, на основе которого определены необходимые проверки и преобразования для ETL.


## 3. Обработка и проверка данных

ETL состоит из четырёх последовательных этапов:

1. **Extract** — чтение исходного CSV и проверка того, что датасет не пустой.
2. **Transform** — преобразование даты и времени эксперимента в `datetime`, а полей `instrument` и `crucible_type` — в категориальный тип.
3. **Validate** — проверка обязательных столбцов и отсутствия пропусков в основных экспериментальных величинах.
4. **Load** — запись ограниченной выборки в PostgreSQL и проверка количества записанных строк.

Исходные значения температуры, относительной массы и ДТГ не сглаживаются и не нормализуются. В экспериментальных данных возможны небольшие колебания сигнала, поэтому автоматическое удаление статистических выбросов не применяется.

На этапах извлечения, преобразования и проверки качества обрабатывается полный датасет. Для записи в учебную базу данных выбираются первые `N` строк, где `N` — целое число от 1 до 100.

## 4. Установка

Для запуска необходим Python версии 3.11 или новее.

Установить пакет можно командой:

```bash
python -m pip install -e .
```

Основные зависимости ETL указаны в `pyproject.toml` и `requirements.txt`.

Дополнительные библиотеки для анализа данных и работы с OpenAlex API указаны в группе `dev` файла `pyproject.toml`.


Для работы с Jupyter Notebook (`EDA.ipynb`) и скриптом OpenAlex дополнительно установите библиотеки из группы `dev`:

```bash
python -m pip install --group dev
```

Для запуска только ETL дополнительные библиотеки не требуются.


## 5. Настройка подключения к PostgreSQL

Для подключения используется локальный файл `.env` с параметрами доступа к базе данных.

Он должен содержать следующие переменные:

```text
HOMEWORK_DB_HOST=
HOMEWORK_DB_PORT=
HOMEWORK_DB_USER=
HOMEWORK_DB_PASSWORD=
HOMEWORK_DB_NAME=
```

Параметры можно подготовить с помощью скрипта `scripts/read_creds.py`, который считывает их из локальной базы SQLite `creds.db`.

```bash
python scripts/read_creds.py
```

Файлы `.env`, `creds.db` и локальные данные исключены из репозитория через `.gitignore`.

Для запуска ETL необходимы действительные учётные данные с правом записи в PostgreSQL.

## 6. Запуск ETL

После установки пакета и настройки подключения выполните из корня проекта:

```bash
python -m etl.main --limit 100
```

Аргумент `--limit` определяет количество строк для записи в БД. Допустимые значения — от 1 до 100.

Посмотреть справку:

```bash
python -m etl.main --help
```

Результат записывается в таблицу `sharypovaas_etl` базы данных `homeworks`.

Если таблица уже существует, повторная запись прекращается, чтобы случайно не перезаписать данные.


## 7. Исследовательский анализ данных

В ноутбуке `notebooks/EDA.ipynb` выполнен разведочный анализ экспериментальных данных ТГА.

Проверены структура и полнота датасета, наличие дубликатов, состав экспериментальных групп, температурный шаг, скорость нагрева и согласованность экспериментальных метаданных.

Построены кривые ТГА и ДТГ при четырёх значениях pH. Для основного минимума ДТГ рассчитаны температура и скорость изменения массы по трём повторным измерениям.

По результатам анализа принято решение сохранять исходные экспериментальные точки без автоматического сглаживания, интерполяции и удаления статистических выбросов.

Для запуска ноутбука необходимо предварительно создать файл `data.parquet` командой:

```bash
python data_loader.py
```

Основная цель EDA — оценка качества и сопоставимости экспериментальных данных перед их дальнейшей обработкой в ETL.


## 8. Дополнительная работа с API

В скрипте `read_api.py` реализовано получение библиографических данных по теме гидрогелей через публичный API OpenAlex.

Результат сохраняется в `openalex_hydrogels.csv`. Этот скрипт является самостоятельной частью проекта и не входит в ETL экспериментальных данных ТГА.
