# OpenAlex Dataset

Датасет научных публикаций по теме гидрогелей, полученный через публичный API [OpenAlex](https://openalex.org/).

Скрипт `read_api.py` обращается к API OpenAlex и получает 100 публикаций по запросу `hydrogel`.

Датасет содержит 6 столбцов: название публикации, год, DOI, количество цитирований, наличие открытого доступа и тип публикации.

Полученные данные сохраняются в формате CSV (`openalex_hydrogels.csv`). Файл исключён из репозитория с помощью `.gitignore`.

## Домашнее задание №7. Загрузка данных в PostgreSQL

В рамках задания реализован этап **Load** ETL-процесса — загрузка данных термогравиметрического анализа (ТГА) гидрогелей в удалённую базу данных PostgreSQL.

### Подготовка

Для установки необходимых библиотек выполните команду:

```bash
pip install -r requirements.txt
```

Для подключения используется файл `creds.db` — локальная база SQLite, содержащая параметры доступа. Скрипт `scripts/read_creds.py` считывает их и сохраняет в файл `.env`.

Файлы `creds.db` и `.env` исключены из Git с помощью `.gitignore`.

### Порядок запуска

1. Поместить `creds.db` в корневую папку проекта.
2. При необходимости создать `data.parquet` с помощью скрипта `data_loader.py`.
3. Подготовить параметры подключения:

   ```bash
   python scripts/read_creds.py
   ```

4. Проверить подключение к удалённой базе данных:

   ```bash
   python scripts/test_connection.py
   ```

5. Записать 100 строк датасета в PostgreSQL:

   ```bash
   python scripts/write_to_db.py
   ```

### Результат

В удалённой базе данных `homeworks` создана таблица `sharypovaas`, содержащая 100 строк и 18 столбцов исходного датасета ТГА.

Для записи используется метод `pandas.DataFrame.to_sql()`. Параметр `if_exists="fail"` предотвращает случайную перезапись существующей таблицы, поэтому повторный запуск скрипта не требуется.

Данные доступа не хранятся в исходном коде и не публикуются в репозитории.
