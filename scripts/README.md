
# Дополнительные скрипты проекта

В этой папке находятся скрипты предыдущих домашних заданий по дисциплине «Инжиниринг управления данными».

Основной ETL-пайплайн находится в `src/etl`. Его описание и инструкция по запуску приведены в корневом `README.md`.

## Домашнее задание №4. Работа с OpenAlex API

Скрипт `read_api.py` обращается к публичному API [OpenAlex](https://openalex.org/) и получает 100 научных публикаций по запросу `hydrogel`.

Для каждой публикации сохраняются:
- Название и год публикации.
- DOI.
- Количество цитирований.
- Наличие открытого доступа.
- Тип публикации.

Результат сохраняется в `openalex_hydrogels.csv` в корне проекта. Этот файл исключён из Git.

### Запуск

Из корневой папки проекта:

```bash
python scripts/read_api.py
```

Для работы необходима библиотека `requests`.

## Домашнее задание №7. Загрузка данных в PostgreSQL

В этом задании реализована запись экспериментальных данных термогравиметрического анализа гидрогелей в PostgreSQL.

### Скрипты

- `read_creds.py` — считывает настройки подключения из SQLite (`creds.db`) и сохраняет их в `.env`.
- `db_utils.py` — создаёт подключение к PostgreSQL.
- `test_connection.py` — проверяет подключение.
- `write_to_db.py` — записывает 100 строк и проверяет их количество.

### Подготовка

Установить пакет и его зависимости:

```bash
python -m pip install -e .
```

Поместить выданный преподавателем файл `creds.db` в корень проекта, затем выполнить:

```bash
python scripts/read_creds.py
```

Файлы `creds.db` и `.env` не публикуются в Git.

### Проверка подключения

```bash
python scripts/test_connection.py
```

### Запись данных

Если файл `data.parquet` отсутствует, его можно создать:

```bash
python data_loader.py
```

Затем запустить:

```bash
python scripts/write_to_db.py
```

Результат — таблица `sharypovaas` в базе `homeworks`, содержащая 100 строк и 18 столбцов.

Параметр `if_exists="fail"` предотвращает перезапись существующей таблицы. Поскольку таблица уже создана при выполнении ДЗ №7, повторно запускать скрипт не требуется.

## Итоговый ETL
